البدء

CommentPull أداة تعمل في المتصفح لاستخراج التعليقات من منشورات فيسبوك وإنستغرام ويوتيوب. تلصق رابط المنشور، وتجري الأداة استدعاءات API مباشرة من متصفحك — لا شيء يمر عبر خوادمنا.

تُعالَج التعليقات المستخرجة كلياً في ذاكرة متصفحك وتُصدَّر كملف Excel أو CSV أو JSON مباشرة إلى جهازك.

يمنحك الحساب المجاني الوصول إلى جميع الميزات بما في ذلك المرشحات وإلغاء التكرار والنطاقات الزمنية ومنتقي الفائز. يمكنك التسجيل ببريدك الإلكتروني فقط — لا بطاقة ائتمانية مطلوبة.

تدعم CommentPull فيسبوك وإنستغرام ويوتيوب. تتطلب كل منصة تقديم رمز وصول حتى يتمكن متصفحك من المصادقة مع API المعني.

الوصول إلى API

تتضمن الأداة دليلاً خطوة بخطوة لإنشاء رموز الوصول مباشرة من Graph API Explorer الخاص بـ Meta. ستحتاج إلى حساب مطور Meta (مجاني) وتطبيق فيسبوك بالصلاحيات المناسبة. يرشدك الدليل الداخلي خلال كل خطوة.

الاستخراج والتصدير

يدعم فيسبوك روابط المنشورات القياسية وروابط pfbid المشفرة. يدعم إنستغرام روابط /p/ و/reel/ و/tv/. يدعم يوتيوب روابط المشاهدة القياسية (watch?v=) وروابط youtu.be المختصرة.

يمكنك تصدير التعليقات كـ Excel (.xlsx) مع ورقة ملخص، أو CSV، أو JSON. تتضمن صادرات Excel بيانات وصفية مثل عدد التعليقات الإجمالي وتاريخ الاستخراج والمنصة.

لا يوجد حد صارم لعدد التعليقات — ستصفح CommentPull استجابة API الكاملة. قد تستغرق عمليات الاستخراج الكبيرة جداً وقتاً أطول بسبب حدود معدل API التي تفرضها Meta أو Google.

نعم. قم بتفعيل وضع الروابط المتعددة في منطقة الإدخال للصق روابط منشورات متعددة. ستُوضع في قائمة انتظار وتُستخرج بالتسلسل، مع دمج النتائج في ملف تصدير واحد.

الخصوصية والأمان

لا. يتم كل الاستخراج مباشرة في متصفحك — لا تلمس بيانات التعليقات خوادمنا أبداً. نخزن فقط حسابك (البريد الإلكتروني + كلمة المرور المشفرة) وجلستك. لقد صممنا النظام بحيث لا نستطيع رؤية بياناتك المستخرجة حتى لو أردنا ذلك.

يسافر رمز الوصول من متصفحك مباشرة إلى نقطة API الخاصة بـ Meta أو Google — ولا يمر أبداً عبر خوادم CommentPull. تعامل مع رموز الوصول ككلمات مرور: أعد إنشاءها إذا اعتقدت أنها تعرضت للاختراق.

تستخدم CommentPull Meta Graph API الرسمي وتتطلب منك المصادقة برمز وصولك الخاص. هذا يعني أنك تصل إلى البيانات المتاحة لحسابك عبر القنوات الرسمية لـ Meta. أنت مسؤول عن التأكد من أن استخدامك للبيانات يمتثل لشروط منصة Meta والقوانين المعمول بها.

استكشاف الأخطاء وإصلاحها

رموز الوصول تنتهي صلاحيتها. تدوم الرموز قصيرة الأمد حوالي 1-2 ساعة؛ وتدوم الرموز طويلة الأمد حتى 60 يوماً. أنشئ رمزاً جديداً من Graph API Explorer وألصقه في حقل الرمز. تأكد من أن الرمز يملك الصلاحيات الصحيحة (pages_read_engagement لفيسبوك، instagram_basic لإنستغرام).

يحدث هذا عادةً بسبب حد معدل API من Meta أو Google. ستعرض الأداة النتائج الجزئية المجلوبة. حاول مرة أخرى بعد بضع دقائق. قد تتطلب المنشورات الكبيرة جداً جلسات استخراج متعددة.

تأكد من نسخ الرابط الكامل من شريط عنوان متصفحك. يجب أن تتضمن منشورات إنستغرام /p/ أو /reel/ أو /tv/ في الرابط. إذا استمرت المشكلة، تواصل معنا مع تنسيق الرابط وسنحقق في الأمر.
