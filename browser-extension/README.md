# CommentPull Lab extension

Experimental prototype for testing visible Facebook comments in your own browser.

1. Open `chrome://extensions` in a Chromium browser.
2. Enable Developer mode and choose Load unpacked.
3. Select this folder.
4. Open a Facebook post you can view, expand comments, then use the extension popup.
5. Open https://commentpull.com/fb-extension-test.html and import results.

This prototype is not production-ready. It reads only comments already rendered in the page and does not bypass login or access controls.
