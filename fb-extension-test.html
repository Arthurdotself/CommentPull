Browser extension lab

Test collecting comments from the Facebook post already open in your browser, without adding a server or changing the live CommentPull extractor.

1. Install the test extension

  1. Download or clone the CommentPull repository to your computer.
  2. Open chrome://extensions in Chrome or another Chromium browser.
  3. Enable Developer mode, choose Load unpacked, and select the repository's browser-extension folder.
  4. Pin the CommentPull Lab extension so it is easy to open.

This prototype is not a Chrome Web Store extension. Safari support is not included in this first test.

2. Collect visible comments

  1. In the same browser, open a public Facebook post you are allowed to view.
  2. Expand the comments and load some comments in Facebook first. The prototype reads visible page content only; it does not bypass login or access restrictions.
  3. Click the extension and press Collect visible comments.
  4. Return to this page and import the saved test results below.
