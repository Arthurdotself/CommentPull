Getting started

CommentPull is a browser-based tool that extracts comments from Facebook, Instagram, and YouTube posts. You paste a post URL, and the tool makes API calls directly from your browser to retrieve the comments — nothing passes through our servers.

The extracted comments are processed entirely in your browser's memory and exported as an Excel, CSV, or JSON file directly to your device.

A free account gives you access to all features including filters, deduplication, date ranges, and the winner picker. You can sign up with just an email address — no credit card required.

CommentPull supports Facebook, Instagram, and YouTube. Each platform requires providing an access token so your browser can authenticate with the respective API.

API access

The tool includes a step-by-step guide for generating access tokens directly from Meta's Graph API Explorer. You'll need a Meta developer account (free) and a Facebook app with the appropriate permissions. The in-app guide walks you through each step.

Extraction & exports

Facebook supports standard post URLs and pfbid encoded URLs. Instagram supports /p/, /reel/, and /tv/ links. YouTube supports standard watch URLs (watch?v=) and shortened youtu.be links.

You can export comments as Excel (.xlsx) with a summary sheet, CSV, or JSON. Excel exports include metadata like total comment count, extraction date, and platform.

There is no hard cap on the number of comments per extraction — CommentPull will paginate through the full API response. Very large extractions (tens of thousands of comments) may take longer due to API rate limits imposed by Meta or Google.

Privacy & security

No. All extraction happens directly in your browser — comment data never touches our servers. We only store your account (email + hashed password) and your session on our backend. We have deliberately architected the system so we cannot see your extracted data even if we wanted to.

Your access token travels from your browser directly to Meta or Google's API endpoint — it never passes through CommentPull's servers. Treat access tokens like passwords: regenerate them if you believe they've been compromised, and use tokens with the minimum permissions required.

CommentPull uses the official Meta Graph API and requires you to authenticate with your own access token. This means you are accessing data that is already accessible to your account through Meta's official channels. You are responsible for ensuring your use of the extracted data complies with Meta's Platform Terms and applicable laws.

Troubleshooting

Access tokens expire. Short-lived tokens last around 1–2 hours; long-lived tokens last up to 60 days. Generate a fresh token from Meta's Graph API Explorer and paste it into the token field. Make sure the token has the correct permissions (pages_read_engagement for Facebook pages, instagram_basic for Instagram).
